# Kabaddi Academy Website

A website developed for Tirath Raj Kabaddi Academy to showcase the academy, share updates, and highlight student achievements.

## Overview

The website serves as an online platform for the academy, providing information about its activities, events, and achievements.

## Features

- **About the Academy:** Introduction and information about the academy.
- **Events:** Details and updates about academy events.
- **Student Results:** Highlights of student participation and achievements in competitions.
- **Academy Information:** Essential details about the academy and its activities.

## Getting Started

Clone the repository:

```bash
git clone https://github.com/pratiksha0gupta/KabaddiAcademy.git
```

Navigate to the project directory:

```bash
cd KabaddiAcademy
```

Open the project in your preferred code editor and run it using the appropriate local development setup.

Built to establish an online presence for Tirath Raj Kabaddi Academy and make its activities, events, and student achievements accessible to visitors.
